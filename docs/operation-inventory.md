# Excel 操作能力清单

本文区分“模型可以选择的插件内置操作”和“Excel 用户常用但当前尚未提供的能力”。版本以 Git 提交为准；本清单随协议和执行器变化更新。

## 当前已内置

### 内容与公式

| 操作 | 功能 | 当前边界 |
| --- | --- | --- |
| `write_values` | 写入文字、数字、布尔值和空值 | 模型需要生成写入矩阵；目标可以是其它已有工作表 |
| `write_formulas` | 写入公式 | 模型生成公式；插件校验尺寸并拦截外部链接、宏函数和网络函数 |
| `transform_text` | 按明确规则清理文本 | 只处理文本常量，保留数字、布尔值、公式和格式；支持大区域本机分批处理 |
| `clear_contents` | 清除内容 | 不清除格式 |
| `lookup_replace` | 按另一张表的两列旧值→新值映射替换单列 | 插件本地读取映射表；目标必须是单列，映射区域必须是两列 |
| `create_sheet` | 新建工作表并可写入初始矩阵 | 新表名称和矩阵受协议限制 |

### 格式与版式

| 操作 | 功能 | 当前边界 |
| --- | --- | --- |
| `format_range` | 字体、字号、颜色、填充、对齐、数字格式、换行、边框 | 按明确参数设置，不读取目标内容 |
| `clear_formats` | 清除格式 | 不清除内容 |
| `copy_formats` | 复制源区域格式 | `sourceSheet` 省略时使用当前选中工作表；可指定其它源表，`sheet/address` 是目标区域 |
| `resize_range` | 行高、列宽、自动适应 | 最多 2000 行、500 列 |
| `merge_cells` / `unmerge_cells` | 合并和拆分单元格 | 合并会检查非左上角内容，避免丢失数据 |
| `conditional_format` | 数值、文本、自定义、色阶、数据条条件格式 | 只向没有既有规则的区域添加 |

### 数据整理与输出

| 操作 | 功能 | 当前边界 |
| --- | --- | --- |
| `sort_range` | 按最多 8 个字段排序 | 要求完整记录区域和表头 |
| `filter_range` / `clear_filter` | 值筛选、条件筛选和清除筛选 | 最多 2000 行；可恢复原筛选状态 |
| `copy_visible_values` | 将筛选/隐藏后可见行的计算值复制为静态值 | `sourceSheet` 省略时使用当前选中工作表；跨表按可见顺序对应，同表要求实际可见行一致，尺寸必须一致 |
| `create_chart` | 创建柱形、条形、折线、饼、面积、散点图 | 按指定源区域创建新图表 |
| `create_pivot` | 在新工作表创建透视汇总 | 需要非空且不重复的表头 |
| `edit_structure` | 在工作表副本中插入或删除整行整列 | 原表不直接改动；一次最多 100 行或 50 列 |

所有内容修改都经过范围、保护、合并、数组/溢出公式检查，并在执行前建立可恢复备份。模型只能返回上述白名单操作，不能返回 VBA、JavaScript 或自定义函数。

## 常见但尚未内置

### 优先补齐的复制和比较能力

| 建议操作 | 常见用法 | 为什么应做成本地原生操作 |
| --- | --- | --- |
| `copy_values` | 将一个区域复制到另一个区域，保留静态值 | 不需要模型读取和重新生成大矩阵，支持跨工作表和大区域 |
| `copy_formulas` | 复制公式并按目标位置调整相对引用 | Excel 原生复制能正确处理相对/绝对引用，模型逐格生成容易错位 |
| 扩展 `copy_formats` | 将 `表1!A1:C1` 格式复制到 `表2!A2:C100` | 已通过 `sourceSheet` 支持，仍需继续补充更多跨表复制测试 |
| 扩展 `copy_visible_values` | 将一张表筛选后的可见行复制到另一张表 | 已通过 `sourceSheet` 支持，跨表按可见顺序对应 |
| `compare_ranges` | 比较两张表或两个区域，返回差异摘要或写入差异标记 | 本地读取和比较可避免把两块大数据全部发送给模型 |

### Excel 中高频的数据处理能力

- 向下填充、向右填充、按模式填充；转置行列。
- 删除重复项、按键合并/去重、拆分文本列、合并多列文本。
- 查找并替换单元格文本的明确字面规则（当前只有映射替换和 `transform_text` 规则替换）。
- 特殊粘贴：只粘贴值、只粘贴公式、只粘贴格式、跳过空白、转置、运算粘贴。
- 表格对象操作：创建表、调整表头/数据区域、表格筛选和表格样式。
- 冻结窗格、隐藏/显示行列、设置打印区域和页面布局。
- 数据验证、下拉选项、批注/评论、超链接和命名区域。

### 分析和读取能力

- 跨工作表读取指定区域并生成对比、匹配、汇总或异常清单。
- 本地查找匹配、连接两个表、按键汇总和缺失项检查。
- 公式结果读取、错误值扫描、依赖关系和循环引用诊断。
- 透视表刷新、既有图表更新和既有条件格式规则管理。

## 建议实现顺序

1. **第一阶段：复制基础**：`copy_values`、`copy_formulas`，并继续完善跨表格式和可见值复制的验证。
2. **第二阶段：跨表数据处理**：扩展可见值复制，增加本地 `compare_ranges`、匹配和差异摘要。
3. **第三阶段：高频粘贴与整理**：填充、转置、删除重复项、拆分列和特殊粘贴。
4. **第四阶段：工作表对象和分析增强**：表格对象、数据验证、冻结窗格、既有对象更新和公式诊断。

复制、匹配和比较优先做成插件原生操作；公式“从需求生成新公式”继续由模型通过 `write_formulas` 完成，公式“从已有区域复制并调整引用”应交给 `copy_formulas` 原生执行。
