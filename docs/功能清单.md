# AI for Excel 功能清单

更新日期：2026-10-26。以下为本项目已开放给模型的操作；模型只能组合这些结构化操作，不执行任意代码。

## 统一对话

- **分析与修改自动判断**：直接输入问题或要求，用户无需选择模式。模型在同一次请求中判断本轮意图：询问、分析、解释、比较和建议只返回结论；要求写入、整理、美化、建图等时生成操作。意图不明确时应先询问，不根据历史修改要求擅自执行本轮操作。
- **只读约束**：只读响应使用 read_only:true，插件拒绝同时包含操作或分步写入决定；补充数据/格式的后续请求保持本轮只读约束。下一条用户请求可以明确要求修改。语义判断仍依赖模型，未据模拟测试声称真实模型必定正确识别。
- **自动分步执行**：简单或相互独立的修改直接执行；依赖前一步结果、创建输出后继续处理或需要中间检查的任务自动规划最多 8 步，每步执行后读取实际结果并检查。不按字数、操作数量或用户自报复杂度划分。支持暂停、继续、补充要求后重做、逆序撤销，以及保留结果结束。计划和恢复记录随工作簿保存，密钥不写入任务记录。
- **已有分步任务**：同一输入框仍可提问或分析，插件强制本轮只读，拒绝新写入和新任务；原任务继续、重做、撤销或结束仍通过任务面板处理。
- **连续对话与清除**：最多保留当前窗格最近 10 轮、合计 40000 字符（按完整问答对淘汰）。历史只保存问题、目标位置和真实结果摘要，不缓存旧单元格矩阵或可执行计划；每次发送重新读取本轮选区。执行失败、暂停及恢复状态会进入上下文。
- 点击“清除对话”，清空消息和历史，下一条从新对话开始；表格修改、恢复记录、分步任务进度和未发送文字保持不变。执行中暂不能清除；刷新或重开窗格后也从新对话开始。所有模型请求不设置固定截止时间，可主动取消。
- 请求模型期间，底部状态栏显示持续计时；计时显示时表示模型请求或补充数据处理仍在进行，模型响应完成或请求结束后自动停止并隐藏。

## 常用命令

- 在输入框旁点击“保存常用命令”，将当前对话框内容保存到本机安装目录的 `user-data/common-commands.json`。文件独立于 Excel 网页缓存和插件版本，更新保留；整个目录由 Git 忽略。
- 文件不存在时迁移旧缓存命令，确认文件存在后移除旧命令键；已有文件优先，不重新导入已删除或修改的旧命令。文件采用原子替换，每次变更保存上一版 `.bak`；文件损坏或写入失败明确报错并保留原文件。
- 点击“常用命令”可打开已保存命令列表；选择后会追加到当前输入内容末尾，不会清除已有内容。
- 右键某条命令显示“修改”和“删除”；Shift+F10 或菜单键也可打开。修改使用独立多行编辑框，可保存或取消；删除只针对该条命令。保存/删除成功后更新本机文件，不影响聊天草稿、工作簿或恢复记录；重复内容及其它窗格已改动/删除的目标会提示处理。点击菜单外、按 Esc 或滚动时收起菜单。
- 命令只保存在当前设备，不写入工作簿或 OneDrive；最多保留最近 50 条，每条最多 2000 字符。

## 连接配置保存

- 地址、模型、供应商及记住密钥的选择保存在安装目录 `user-data/connection.json`，更新保留且 Git 忽略；清理或切换 Excel 网页缓存不影响该文件。
- 首次打开迁移旧连接配置，已有文件优先；文件确认保存后才删除旧连接键。密钥只在勾选后保存，取消勾选或清除时移除；切换接口/供应商不复用旧密钥。备份 `.bak` 不包含密钥。
- 文件原子保存，失败或损坏明确报错；快速修改按顺序提交，确认落盘后才提示保存或清除成功。配置仅在本机保存，密钥未额外加密，不写入工作簿、源代码或日志。执行错误会在本地宿主日志中保留受限诊断信息，便于检查错误阶段和操作目标。

## 使用边界

- 发送时的选区用于提供模型上下文，不再限制操作目标的工作表或地址；模型必须在每个操作中明确填写目标 sheet 和本地 A1 address。整列/整行选择仍按已用区域提供数据，写入时应使用实际行号范围（例如 G2:G117），不能把对应行误扩展为 G:G。
- 写入值或公式前会检查目标区域。目标单元格已有内容或公式时，执行结果会明确提示覆盖了哪些目标区域；不会静默把已有内容当成空白。
- 首轮只发送选区元数据；值、公式、统计和查找等任务需要时才读取值/公式，模型可在 `data_request.ranges` 中指定当前选区以外的工作表和连续 A1 区域，插件读取后通过 `selection.supplemental_ranges` 回传。依赖外观判断时只读取格式。格式复制使用源区域和目标区域的原生格式复制，不读取目标区域内容。可见单元格复制使用 Excel 的可见区域视图，只读取当前可见行的计算值并写入对应可见行，隐藏行不改动。映射替换由本地执行器读取指定参考工作表的两列映射，不要求模型读取跨表内容；重复旧名称对应不同新名称时停止并提示。值、公式、新表数据及文本清理的单个目标最多 100000 格，插件自动分批提交，每批最多 2000 格；读取、格式和清除等单个区域仍最多 100000 格。一轮最多 20 个操作，区域处理量累计最多 200000 格。模型请求、响应和操作计划的文字体积限制仍生效，规则化清理不生成全量回写矩阵。
- 文本清理支持删除所有空白（含不间断空格、全角空格、制表符和换行）、去首尾空白或合并连续空白；可另去除 U+200B/U+2060/BOM，或按最多 20 项明确字面规则替换（可限定整格相等）。保留数字、布尔值、公式、格式及文本前导零，不猜测“占位符”所指字符。状态栏显示已处理格数，可取消；失败或取消自动恢复整轮，而非仅恢复最后一批。
- 行高会影响整行，列宽会影响整列；手动尺寸单位是磅，不是 Excel 界面显示的字符列宽。最多一次调整 2000 行、500 列；筛选最多 2000 行。
- 合并时，除保留位置外的其它单元格只要存在内容或公式就拒绝执行，避免静默丢失数据。操作涉及已有合并单元格时，选区必须包含完整合并区域；写入、排序、筛选或条件格式前须先拆分。
- 条件格式只添加到当前没有条件格式的选区，不覆盖已有规则；新规则可随该轮恢复移除。不提供任意修改/删除已有复杂条件格式规则。
- 图表来源是选区，生成于当前工作表；不会自动覆盖现有图表。透视表输出到新工作表，数据第一行需为非空且唯一的文字字段名。
- 行列插删必须单独一轮，并明确在命名的新副本中执行，原工作表不变。一次最多插删 100 行或 50 列；源表已用区域最多 100000 格。若需继续美化，先切到副本并重新选区发送要求。
- Excel 表格对象内支持格式调整、图表、透视分析和结构副本；其它数据修改、排序筛选请先转为普通区域。数组、溢出公式及受保护区域仍不直接修改。
- 不开放 VBA、宏、任意 JavaScript/其它脚本、外部数据公式或宏函数。

## 恢复行为

恢复单元格内容和格式、合并状态、该轮修改的行高列宽和筛选状态；删除该轮创建的图表或新工作表。行列插删的恢复是删除新副本，不在原表做反向插删。

直接处理的恢复会覆盖目标区域在操作后发生的手动修改，只保留最近一轮，刷新或关闭窗格后记录失效。分步任务保留各步备份，继续或重做前检查记录区域变化；发现手动修改则停止。执行期间关闭窗格的中断恢复可能覆盖该步骤区域后续修改。对尺寸和筛选，也会还原对应行列/筛选状态；恢复时删除相应步骤创建的对象。“保留结果并结束”会释放任务恢复记录。

清空选区内容、清除格式和格式设置是不同操作。例如清除格式可移除原边框；新增或调整边框应使用边框设置。

- 底部状态栏按实际节点更新：提交请求、等待模型、接收响应、校验结果、补充数据/格式、执行操作及完成；显示模型请求轮次，格式重试也会提示。

- 模型请求使用流式接收。模型可在最终 JSON 之前返回独立 progress 进展行，状态栏即时显示面向用户的任务阶段说明；普通对话与分步规划/执行/检查均接入。不会显示 reasoning_content 等内部推理字段，也不会提前执行部分操作。
- 实时反馈取决于模型主动发送进展以及接口透传流；中转缓冲或只返回普通 JSON 时仍可完成任务，但不能保证过程实时显示。流中断、缺少结束信息、拒绝或最终协议无效时停止执行。
