# AI for Excel

AI for Excel 是一个基于 Office.js 的 Excel 加载项。它让用户可以在任务窗格中用自然语言分析工作表、整理数据和执行常见的格式与结构操作。

项目当前以本地开发和自定义模型接口为主，适合希望在自己的 Excel 环境中试用、开发或扩展的用户。

## 主要功能

- 读取当前选区并进行数据分析
- 写入值、公式，清除内容和格式
- 批量格式调整、排序、筛选、条件格式和图表
- 跨工作表复制、映射替换和可见单元格复制
- 分批处理大范围数据，并在失败时恢复修改
- 保存最近的恢复记录和本机常用命令
- 支持 OpenAI 兼容接口及用户自定义接口

## 源码开发

详细的安装、配置和开发步骤见 [Office.js 使用说明](officejs/README.md)。

需要 Node.js 22.18+ 或 Node.js 24，以及 Microsoft 365 Excel。

```powershell
cd path\to\aiforexcel\officejs
npm ci
npm start
```

## 直接使用安装版

下载项目后，按以下步骤使用：

1. 下载项目压缩包并解压到本机目录。
2. 双击根目录中的 `install.cmd`，按提示完成安装。
3. 打开或重新启动 Excel，在“开始”选项卡中打开 **AI for Excel**。
4. 在任务窗格的“连接设置”中填写自己的 Base URL、模型和 API Key。
5. 新建一个测试工作簿，选择少量单元格，先发送只读分析请求确认连接正常。

`install.cmd` 会自动准备 Node.js 24、安装依赖并完成构建和注册。首次使用前请确认模型接口允许来自本机加载项页面的请求。

## 隐私与本地数据

工作簿数据只会在用户发起请求后按当前任务需要发送到用户配置的模型接口。连接设置保存在本机安装目录的 `user-data` 文件夹中，该目录已加入 Git 忽略规则。API Key、工作簿文件、运行日志和构建产物不会提交到仓库。

## 项目状态

项目仍在积极开发中。Office.js 宿主兼容性、模型输出质量和不同 Excel 版本的行为需要在目标环境中单独验证。
