# AI for Excel 待办清单

本清单记录后续需求；列入清单不表示立即实施。优先处理用户当前指定的任务。

- [x] **API 配置改为独立文件持久化**（2026-10-26 已实施）
  - 在插件本地文件目录下建立专用配置文件夹，单独保存接口地址、模型、供应商及用户选择记住的 API Key，不再将 Excel 网页缓存作为配置的持久保存位置。
  - 将整个配置文件夹加入 `.gitignore`，配置及密钥仅保存在本机，不提交或上传 GitHub。
  - 兼容并迁移现有配置；插件重启、Excel 缓存清理或切换后仍能读取已保存的配置，安装更新不覆盖用户配置。
  - 已保存到安装目录 `user-data/connection.json`；迁移当前配置、原子保存、密钥仅在勾选时保留。备份不含密钥，清除后不会从旧缓存重新导入。129 项自动测试、41 项原生 Excel 验证及文件配置真实模型连接通过。

- [ ] **连接设置改为“保存的连接”**（优先级：低，非紧急）
  - 支持保存、命名、编辑和切换多套连接，包含接口地址、模型及仅保存在本机的密钥。
  - 示例：“OpenRouter 免费”“DeepSeek 官方”“自用中转”。
  - 内置供应商作为新增连接时的填写模板，减少与自定义地址功能的重复。
  - 保留手动填写地址、模型及刷新模型列表的能力，并兼容已有配置。
  - 密钥按上述独立文件持久化要求保存在本机专用配置文件夹，不写入源代码，不通过 GitHub 或 OneDrive 同步。

- [ ] **规划正式发布与账号付费架构**（优先级：高，发布前完成）
  - 评估两种前端交付方式：云端/内网 HTTPS 托管，或本地服务伴随安装包；比较安装包大小、首次安装权限提示、证书配置、端口占用、自动启动、升级和卸载体验。
  - 正式发布时优先考虑云端或内网 HTTPS 托管前端，避免每台电脑安装 Node.js 运行时；若采用本地服务，安装过程应尽量静默，并提供服务状态、升级和卸载处理。
  - 账号登录、订阅权益、额度和设备状态必须由云端服务校验，本地网页和本地服务不能作为授权安全边界。
  - 规划登录与令牌机制：插件前端使用短期访问令牌，云端接口负责续期、撤销和订阅校验；必要时增加设备激活和并发设备限制。
  - 规划模型调用架构：付费模式下由云端模型代理调用供应商 API，供应商密钥不放入插件；继续支持用户自带 API Key 时，明确其属于绕过平台计费的独立模式。
  - 评估云端部署的跨域、隐私、数据留存和区域合规要求，并在产品说明中明确选区数据的发送范围。
