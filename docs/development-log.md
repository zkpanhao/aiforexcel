## 2026-10-20：Office.js 改造基础

- 建立 Office.js 改造目录；现有 VBA 版本继续保留在 Excel 加载项中，作为过渡和对照。
- 接入中转地址、手动模型输入、实时模型列表和密钥字段。密钥默认只在页面内存使用；勾选“记住密钥”后保存到本机加载项存储，并可主动清除；地址和模型同步保存。
- 完成普通区域读写、公式、清除内容和格式、原生区域备份、一步恢复、失败回退及执行前范围检查。
- 修复 TypeScript、Webpack 与 manifest schema；自动检查覆盖协议、请求、执行顺序和恢复路径。
- 中转跨域 OPTIONS 预检返回 204，允许本地加载项来源；当时尚不能据此证明带密钥的完整模型请求成功。
- 增加本地 HTTPS 开发和桌面 Excel 侧载入口；真实 Excel 验收步骤见 [`testing.md`](testing.md)。
- 已侧载到 Microsoft 365 Excel，宿主报告 ExcelApi 1.13 可用，并成功读取选区。
- 原生 Excel 自检通过清除内容/格式，恢复混合字体、字号、颜色、填充、换行、边框、数字格式及公式，字面量/空值写入，区域数字格式矩阵和两轮恢复；测试临时表已删除。
- 启动入口改为隐藏后台服务，通过真实 HTTPS 页面识别服务，避免微软开发工具将 FinWait 状态连接误判为服务已启动。
